# Мыс Доброй Надежды · TAQO

Мобильная страница выбора площадки для отзыва. Статический HTML/CSS, без зависимостей, аналитики и автоматических перенаправлений.

## Ссылки

- Яндекс: https://yandex.ru/maps/org/mys_dobroy_nadezhdy/243689236906/reviews/?add-review=true
- 2ГИС: https://2gis.ru/spb/firm/70000001100879421/tab/reviews

Обе ссылки находятся непосредственно в index.html и открываются в той же вкладке. Яндекс использует документированный параметр открытия формы `add-review=true`; 2ГИС ведёт на вкладку отзывов. Авторизация, подтверждение открытия приложения и фактический экран в установленном приложении управляются площадками и ОС. Не обещаем автоматическую публикацию или отсутствие системных запросов.

## Публикация

GitHub → Settings → Pages → Deploy from a branch → main → / (root) → Save.
Ожидаемый адрес после включения Pages: https://taqoup.github.io/misdobroinadejdi/

После публикации проверить обе кнопки на реальном iPhone и Android, с приложениями и без них. На NFC записать адрес этой страницы.

Фон — художественная стилизация под морскую карту, не навигационная или историческая карта. Текст и кнопки — отдельные доступные HTML-элементы. Все изображения хранятся в репозитории.

## Макет по референсу

Страница сохраняет пропорции референса 852 × 1846. Ширина ограничена 520 px; на узких экранах размеры текста, отступы и кнопки масштабируются через container query units (`cqw`). Высота зависит от ширины, поэтому на коротком экране страница прокручивается без обрезания содержимого и растягивания карты.

`assets/nautical-reference.jpg` — фон, подготовленный встроенным ImageGen по предоставленному референсу. Текст, разделители и интерактивные кнопки реализованы в HTML/CSS/SVG. Прежние изображения сохранены.

Промпт фона: сохранить пропорции и светлую фактуру референса, канат слева сверху, обрезанный компас справа сверху, карту справа, корабль слева, пунктирный маршрут и розу ветров; убрать типографику, декоративные разделители, карточки кнопок, логотипы, сердце и подпись; заполнить освобождённые области пергаментом без новых объектов.
